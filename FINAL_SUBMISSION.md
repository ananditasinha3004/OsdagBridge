# OsdagBridge Testing - Final Submission Index

This branch consolidates the complete testing submission for the three assigned
areas. It is based on `Nidhikhare12/OsdagBridge` `dev` commit
`d74f56dd7f22925fb8148cabf5740ed8d1e39ff3`.

## Submission contents

- `testing/task1/`: rigorous basic, additional-input, and custom-property
  testing across TC-01 through TC-17, including OSI files, dictionaries,
  workbooks, screenshots, logs, scripts, notes, and the Task 1 report.
- `testing/task2/`: three consecutive same-session designs with unlock/edit/run
  state checks, per-run OSI files and dictionaries, plots, CAD captures, report,
  scripts, and screencast.
- `testing/task3/`: comprehensive UI/Input Dictionary/Output Dictionary/workbook/
  output-dock verification, all-component coverage, CAD/plot checks, live issue
  links, report, scripts, and screencast.
